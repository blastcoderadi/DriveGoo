Technical Architecture Summary

The metrics on this report are calculated at runtime using Spring Data JPA aggregate queries and Hibernate single-table inheritance.

  • Aggregate Queries: COALESCE(SUM(b.totalAmount), 0) ensures non-null values even when zero bookings exist.
  • Database Locking: @Lock(LockModeType.PESSIMISTIC_WRITE) guards overlapping booking creation against concurrency races.
  • Auditing: Invoices freeze pricing snapshots so historic reports remain immutable even when vehicle rates update.
